# Data

```
data/
  raw/         where the original datasets come from (nothing stored here, see raw/README.md)
  processed/   what preprocessing produces and where it lives (16 kHz audio, teacher targets)
  splits/      one CSV per dataset with every file used, its label, duration and split
```

Audio is not stored in git. The archives and caches are on our Google Drive (`MyDrive/MT2KD/datasets/`, `MyDrive/MT2KD/cache16k/`).

## Datasets

| Task | Dataset | License | Used for training | Validation | Test |
|---|---|---|---|---|---|
| ASR | LibriSpeech | CC BY 4.0 | 30 h subset of train-clean-100 | dev-clean | test-clean |
| AT | FSD50K | CC BY 4.0 (clip licences vary, CC0 / CC BY / CC BY-NC) | 15,000 clips of the official train split, 200 classes | official validation split (4,170 clips) | FSD50K eval split not used (see results) |
| SV | VoxCeleb1 | CC BY 4.0 (metadata); audio from YouTube | 30,000 utterances, 1,171 speakers | held-out speakers of the dev set | VoxCeleb1-O cleaned trial list (`veri_test2.txt`, 37,720 trials) |

## Split CSV schema (`data/splits/<dataset>.csv`)

| Column | Meaning |
|---|---|
| filename | path inside the dataset (LibriSpeech: path in the tar; FSD50K: `<id>.wav`; VoxCeleb1: `<speaker>/<video>/<nnnnn>.wav`) |
| label | ASR: transcript; AT: class names joined with `;`; SV: speaker id |
| duration | seconds (original file, before any crop) |
| split | train / validation / test |
| source | corpus and part, e.g. `LibriSpeech/test-clean` |
| speaker | reader / speaker id (empty for FSD50K) |

The CSVs and `leakage_check.json` are generated by `notebooks/00_data/make_splits_and_dataset_stats.ipynb`, which uses `src/data/make_splits.py` and the same selection functions and seeds as the training runs.

## Fixed seeds

- LibriSpeech subsets: nested 2 h ⊂ 10 h ⊂ 30 h, selected by `prepare_manifests` in `src/mt2kd/asr_module.py` (fixed rule, versioned as `SELECTION_VERSION`).
- FSD50K: `subset_idx(n_train, 15000, 0)` in `src/mt2kd/at_module.py` = `numpy.random.default_rng(42)` permutation of the official train split, first 15,000 clips.
- VoxCeleb1: `numpy.random.default_rng(42)` permutation, first 30,000 utterances.
- Training order and initialisation: seed 42 in every run.

## Zero leakage

- LibriSpeech and VoxCeleb1 test speakers are disjoint from the training speakers by design of both corpora. We only sample inside the official training parts, and the VoxCeleb1 step of every training notebook asserts that no training or validation speaker appears in the official test set.
- `data/splits/leakage_check.json` lists the speaker overlap and the file overlap for every pair of splits.
- LM decoding settings were tuned on half of the dev-clean speakers and reported on the other half and on test-clean.

## Class imbalance

FSD50K is strongly imbalanced (see `results/dataset_stats/class_balance_fsd50k.png`). No oversampling or re-weighting was used: Stage 1 learns from the teacher's soft scores for every class, and Stage 2 uses plain multi-label BCE, as in the base paper. Results are reported as mAP, which averages over classes.
